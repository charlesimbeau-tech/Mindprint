# 🧠 Mindprint

A free, client-side mental health screening tool featuring 23 validated clinical instruments. No data leaves the browser — complete privacy by design.

🔗 **Live:** [charlesimbeau-tech.github.io/Mindprint](https://charlesimbeau-tech.github.io/Mindprint/)

## Features

- **23 validated instruments** — PHQ-9, GAD-7, PCL-5, AUDIT, and more
- **Triage questionnaire** guides users to the right screening
- **PDF export** of results for personal records or clinician review
- **100% client-side** — zero data transmission, full privacy
- **Responsive design** for mobile and desktop

## Instruments

Includes standardized screenings for depression, anxiety, PTSD, substance use, eating disorders, OCD, and other conditions using peer-reviewed instruments.

## Tech Stack

- HTML / CSS / JavaScript
- GitHub Pages (hosting)

## Local Setup

```bash
git clone https://github.com/charlesimbeau-tech/Mindprint.git
cd Mindprint
npx serve .
```
